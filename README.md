# Trek & Sleep V2.8

V2.8 baut auf der stabilisierten V2.7 auf und bündelt mehrere größere Erweiterungen.

## Neu: Tour-Cockpit
- zentrale Übersicht über GPX-Länge, geplante Strecke, POIs und gespeicherte Touren
- Status: Tour bereit, GPS, Anreise oder Live-Navigation
- Schnellzugriff auf POIs, Tourplanung, Warncenter und Höhenprofil
- zeigt wichtige Wasser-, Hütten- und Rettungspunkte

## Neu: Anreise zum Tourstart
- Vor-Tour-Modus zeigt weiterhin die Luftlinie zum Start
- neuer Button „Route zum Tourstart öffnen“
- öffnet auf dem iPhone Apple Maps mit dem geplanten Tourstart als Ziel

## Neu: Daten-Backup
- Export aller Trek-&-Sleep-LocalStorage-Daten in eine einzelne JSON-Datei
- Import/Wiederherstellung derselben Daten
- gedacht für Versionswechsel, Browserwechsel und zusätzliche Sicherheit

## Neu: Routenwerkzeuge
- GPX-Richtung umkehren
- Start/Ziel und Planungspunkte werden dabei mitgedreht
- Navigationseinstellungen, Rechts-Layer und Warncenter zentral erreichbar

## Stabilität
Die V2.7-Distanz- und GPS-Zustandslogik bleibt die Grundlage. V2.8 verändert sie nur dort,
wo das Tour-Cockpit bzw. die Anreise-Funktion darauf zugreifen.

## GitHub Pages
Für ein Update im bestehenden Repository einfach die sechs Dateien aus diesem Paket
in das gleiche Repository hochladen und die vorhandenen Dateien ersetzen. Die Pages-Adresse
bleibt gleich.
